# Third-party notices

Hisingen is released under the [MIT License](LICENSE). It bundles Sparkle, the gRPC Swift
libraries and the SwiftNIO and Swift packages beneath them, and calls a few outside services. Parts of the research and implementation were done with an AI coding assistant
that used web search, and that is how code from other projects reached early versions of the
app. This file lists what that covers, where each part came from, and under which terms.


## At a glance

| Component | What Hisingen has from it | License | Used for |
|---|---|---|---|
| Polaris | A few code fragments | MIT, Copyright (c) 2026 Simon Busborg | Polestar API code |
| pypolestar, polestar_api | API knowledge | MIT, Copyright (c) 2023 Tuen Lee | Polestar API support |
| unofficial-polestar-api | API knowledge and two header values | MIT, Copyright (c) 2025 | Polestar API gRPC and app-backend support |
| Sparkle | Bundled library | MIT, plus bundled components | Signed in-app updates |
| 20 gRPC Swift, SwiftNIO and Swift packages | Linked libraries | Apache 2.0; BoringSSL inside swift-nio-ssl and swift-crypto is ISC and OpenSSL | Polestar gRPC connections |
| Open-Meteo | Weather data at runtime | CC BY 4.0 | Vehicle Weather |
| Elpriset just nu.se | Spot prices at runtime | Credit requested | Charging planner |
| Volvo Cars APIs | Vehicle data at runtime | Volvo Cars developer terms | Volvo support |
| Polestar interfaces | Vehicle data at runtime | Polestar's terms | Polestar support |

## Functionality adapted from other projects

### Polaris

[simonbusborg/polaris](https://github.com/simonbusborg/polaris) by Simon Busborg, MIT
License, Copyright (c) 2026 Simon Busborg.

Hisingen's Polestar support includs/included the following code from Polaris unchanged.
It came in when an AI coding assistant with web search was used to improve Hisingen's Polestar API
support:

* the protobuf helpers `Protobuf.varint`, `Protobuf.stringField` and `Protobuf.grpcFrame`, in
  [PolestarGRPC.swift](Sources/Hisingen/Services/API/PolestarGRPC.swift)
* in the same file, the battery request message and its field 3 read (`fetchBattery`), and the
  C3 discovery reply parsing of `c3.grpcHost` and `c3.grpcPort` (`c3Host`)
* the six sign-in resume-path patterns in `extractResumePath`, and the `GetCarImages` request
  body and headers in `fetchCarImage`, both in
  [PolestarAPI.swift](Sources/Hisingen/Services/API/PolestarAPI.swift)

### pypolestar and polestar_api

[pypolestar/pypolestar](https://github.com/pypolestar/pypolestar) and
[pypolestar/polestar_api](https://github.com/pypolestar/polestar_api) by Tuen Lee, MIT
License, Copyright (c) 2023 Tuen Lee.

Polestar does not document its backend, and pypolestar is the public reference for it.
Hisingen took API knowledge from pypolestar for parts of its Polestar support.

### unofficial-polestar-api

[kildahldev/unofficial-polestar-api](https://github.com/kildahldev/unofficial-polestar-api), MIT
License. Its LICENSE file reads "Copyright (c) 2025" and names no holder; the text is otherwise the
same as the MIT text below.

Hisingen's source cites it for cross-checking the meaning of Polestar gRPC fields (charge
locations, air quality, charge-location writes) against its proto schema and client.

## Software bundled with the app

### Sparkle

[sparkle-project/Sparkle](https://github.com/sparkle-project/Sparkle), pinned in
[Package.resolved](Package.resolved) (2.10.1 when last reviewed), MIT License.
`Sparkle.framework` performs the signed in-app updates.

Sparkle's license file also covers four bundled components under their own terms:

* bsdiff 4.3 (`bspatch.c`, `bsdiff.c`): Colin Percival, BSD-style license
* sais-lite: Yuta Mori, MIT license
* Ed25519 C implementation from [orlp/ed25519](https://github.com/orlp/ed25519): Orson Peters,
  zlib license
* `SUSignatureVerifier.m`: Mark Hamlin, BSD-style license

The full text is
[Sparkle's LICENSE at 2.10.1](https://github.com/sparkle-project/Sparkle/blob/2.10.1/LICENSE).
Built apps also carry a copy as `Sparkle-LICENSE.txt` in `Contents/Resources`.

## Data services

Called at runtime. No code from them ships in Hisingen.

* **[Open-Meteo](https://open-meteo.com/):** weather for Vehicle Weather, from
  `api.open-meteo.com`. Weather data by Open-Meteo.com, licensed
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The README credits it and the
  Vehicle Weather row in Settings names it. The free API is for non-commercial use, so check
  Open-Meteo's terms before charging for Hisingen or any part of it. Vehicle coordinates are
  sent while the feature is on; see [PRIVACY.md](PRIVACY.md).
* **[Elpriset just nu.se](https://www.elprisetjustnu.se/):** Swedish spot prices in the charging
  planner, from `www.elprisetjustnu.se`. Prices are provided by Elpriset just nu.se, which asks
  for a credit when its data is shown publicly. The charging planner names it next to the
  prices.
* **Map links:** the location buttons open Apple Maps (`maps.apple.com`) or Google Maps
  (`maps.google.com`, `www.google.com/maps`) with the vehicle's coordinates in the link. Nothing
  is sent to either until the user clicks.

## Vehicle provider interfaces

* **Volvo Cars:** the APIs are published for third-party developers and used under the
  [Volvo Cars Developer Portal terms](https://developer.volvocars.com/terms-and-conditions) and
  any API-specific terms of the account that registers the application. Hosts:
  `api.volvocars.com` and `volvoid.eu.volvocars.com`.
* **Polestar:** credentials for the Developer Portal (the EU Data Act "Data Portal" API) are
  issued under Polestar's terms. The sign-in, GraphQL and gRPC interfaces are not publicly
  documented. Hisingen's support for them comes from public community research and Hisingen's own
  testing. Polestar can change them without notice, and its terms of service may restrict their
  use. See the
  [README disclaimer](README.md#disclaimer). Hosts: `polestarid.eu.polestar.com`,
  `www.polestar.com` (sign-in redirect), `pc-api.polestar.com` and `api.pccs-prod.plstr.io`.
  C3 discovery uses `cnepmob.volvocars.com`, a Volvo Cars host.

## Images and symbols

* **Vehicle images:** renders of the user's own car are downloaded at runtime from Polestar's
  public image API or the Volvo Cars API and cached on the user's Mac. They belong to Polestar
  and Volvo Cars. The app's resources contain no vehicle images.
* **SF Symbols:** the in-app icons are SF Symbols, used under Apple's SF Symbols license.
